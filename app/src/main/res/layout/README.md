# 📒 Kharchabook - Personal Expense Tracker

A beautifully designed Android expense tracking app built with
Kotlin, Room Database, and MVVM Architecture.

## ✨ Features

- 📚 Multiple expense books (Home, Family, Personal etc.)
- 💰 Monthly budget tracking per book
- 📊 Visual spending summary with Pie Chart
- 📅 3 months expense history
- ✏️ Add, Edit and Delete expenses
- 🏷️ Category wise tracking (Food, Transport, Bills etc.)
- 📈 Progress bar showing budget consumption
- 🔔 Over budget alert

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Kotlin | Primary language |
| Room Database | Local data storage |
| MVVM Architecture | Clean code structure |
| LiveData | Reactive UI updates |
| ViewModel | Lifecycle aware data |
| Material Design 3 | Modern UI components |
| MPAndroidChart | Pie chart visualization |
| ViewBinding | Safe view access |
| Coroutines | Background operations |
